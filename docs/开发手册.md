# S-AES 程序开发手册

本手册说明程序的模块划分、算法约定和公开接口，供同组同学联调、答辩讲解
或后续扩展使用。

---

## 1. 设计目标

* **算法与界面分离**：`saes/` 只做密码学运算，不导入任何 GUI 代码；
  `gui/` 只做输入输出与流程编排。两者可以独立测试、独立复用。
* **纯标准库**：算法和界面只依赖 Python 标准库（Tkinter 随 Python 安装）。
  截图脚本是可选的开发工具，才需要 Pillow。
* **可校验**：所有关键常量（S 盒、矩阵、RCON）集中定义；对照公开向量
  的测试随代码一起提交。
* **可解释**：核心加解密提供 `trace_*` 接口，逐轮返回中间值，GUI 直接
  渲染成表格。

---

## 2. 模块结构

```
gui/app.py  ──调用──>  saes/__init__.py
   │                     ├── core.py      分组密码本体
   │                     ├── text.py      字符串扩展（第 3 关）
   │                     ├── vectors.py   交叉测试（第 2 关）
   │                     ├── multi.py     多重加密（第 4 关）
   │                     └── modes.py     CBC（第 5 关）
   └── theme.py         仅 GUI 使用的设计 token 与 ttk 样式
```

依赖方向是单向的：`gui → saes`，`saes` 内部 `text/vectors/multi/modes → core`。
`core` 不依赖任何其他业务模块。

## 3. 数据表示与算法约定

### 3.1 分组与状态矩阵

* 16 bit 分组用 `int`（`0x0000 ~ 0xFFFF`）表示；
* 状态直接使用 2×2 元组，下标与教材图 D.2 一致：

```python
State = tuple[tuple[int, int], tuple[int, int]]   # ((s00, s01), (s10, s11))
```

* 16 bit 分组按**列优先**填入状态（前 8 bit 第一列，后 8 bit 第二列）：

```
state_from_block(0xABCD) == ((0xA, 0xC), (0xB, 0xD))
```

* 轮密钥也转成同样的 2×2 状态，因此 `add_round_key` 就是逐格异或。

### 3.2 轮函数（附录 D.1 ~ D.2）

四个基本变换与教材同名，函数名一一对应：

| 教材 | 函数 | 作用 |
|---|---|---|
| `AK` | `add_round_key` | 状态与轮密钥逐位异或 |
| `NS` | `nibble_substitution` | 查 S 盒 |
| `SR` | `shift_rows` | 第二行循环左移一个半字节 |
| `MC` | `mix_columns` | 每列左乘 `[[1,4],[4,1]]` |
| `INS` | `inverse_nibble_substitution` | 查逆 S 盒 |
| `ISR` | `inverse_shift_rows` | 第二行循环右移 |
| `IMC` | `inverse_mix_columns` | 每列左乘 `[[9,2],[2,9]]` |

复合函数（从右向左执行）：

```
加密 = AK2 ∘ SR ∘ NS ∘ AK1 ∘ MC ∘ SR ∘ NS ∘ AK0
解密 = AK0 ∘ INS ∘ ISR ∘ IMC ∘ AK1 ∘ INS ∘ ISR ∘ AK2
```

乘法的模多项式为 `x⁴ + x + 1`，实现中用预计算的 `MUL2/MUL4/MUL9`
查表完成（对应附件 D.1 表 D.2(b)）。

### 3.3 密钥扩展（D.3）

主密钥拆成 `w0`（高字节）和 `w1`（低字节）：

```
w2 = w0 ⊕ RCON(1) ⊕ SubNib(RotNib(w1))
w3 = w2 ⊕ w1
w4 = w2 ⊕ RCON(2) ⊕ SubNib(RotNib(w3))
w5 = w4 ⊕ w3

K0 = 主密钥，K1 = w2‖w3，K2 = w4‖w5
RCON(1) = 0x80，RCON(2) = 0x30
```

教材示例：`K = 2D55` → `w2=BC, w3=E9, w4=A3, w5=4A`，
即 `K1=BCE9`、`K2=A34A`。`key_expansion_rows()` 返回的就是这张逐步明细表。

### 3.4 字符串分组

* 字符串先按 UTF-8 编码为字节；
* 每 2 字节（16 bit，大端）为一组；
* 不足一组时使用 PKCS#7 填充：缺 1 字节补 `01`，缺 2 字节补 `02 02`；
* 解密端校验并去除填充。

## 4. 接口文档

### 4.1 `saes.core`

#### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `BLOCK_BITS` | `16` | 分组长度 |
| `KEY_BITS` | `16` | 主密钥长度 |
| `SBOX` | 16 元组 | S 盒，索引与输出均为 0~15 |
| `INV_SBOX` | 16 元组 | 逆 S 盒 |

#### 异常

`SaesError(ValueError)`：所有输入位数、格式、长度、填充错误都抛这个异常，
GUI 统一捕获并弹窗。

#### `expand_key(key: int) -> KeySchedule`

把 16 bit 主密钥扩展为 3 个轮密钥。

```python
from saes.core import expand_key

schedule = expand_key(0xA73B)
schedule.k0, schedule.k1, schedule.k2
# (0xA73B, 0x1C27, 0x7651)
```

* 参数 `key`：0 ~ 0xFFFF；
* 返回冻结数据类 `KeySchedule(k0, k1, k2)`，另有属性
  `round_keys`、`words`（`w0 ~ w5`）和 `states()`（2×2 轮密钥）；
* 异常：密钥越界。

#### 状态与基本变换

| 接口 | 说明 |
|---|---|
| `state_from_block(block) -> State` | 按图 D.2(a) 列优先拆成 2×2 |
| `state_to_block(state) -> int` | 把 2×2 状态拼回 16 bit |
| `add_round_key(state, round_key)` | `AK` |
| `nibble_substitution(state)` | `NS` |
| `inverse_nibble_substitution(state)` | `INS` |
| `shift_rows(state)` | `SR` |
| `inverse_shift_rows(state)` | `ISR`（2 列时与 `SR` 相同） |
| `mix_columns(state)` | `MC` |
| `inverse_mix_columns(state)` | `IMC` |
| `encrypt_state(state, schedule)` | 教材加密复合函数 |
| `decrypt_state(state, schedule)` | 教材解密复合函数 |

```python
from saes.core import add_round_key, mix_columns

add_round_key(((0xA, 0x4), (0x7, 0x9)), ((0x2, 0x5), (0xD, 0x5)))
# ((0x8, 0x1), (0xA, 0xC))   —— 附录 D.2.1 的算例

mix_columns(((0x6, 0x4), (0xC, 0x0)))
# ((0x3, 0x4), (0x7, 0x3))   —— 附录 D.2.4 的算例
```

#### `key_expansion_rows(key) -> list[tuple[str, int, str]]`

返回 `w0 ~ w5`、`g(w1)`、`g(w3)` 的逐步明细 `(名称, 字节值, 说明)`，
GUI 的密钥扩展表直接遍历它。

#### `encrypt_block(plaintext: int, key: int) -> int`

加密一个 16 bit 分组。

```python
from saes.core import encrypt_block
encrypt_block(0x6F6B, 0xA73B)   # 0x0738
```

#### `decrypt_block(ciphertext: int, key: int) -> int`

解密一个 16 bit 分组，是 `encrypt_block` 的逆运算。

#### `make_schedule(key) -> tuple[State, State, State]`

返回以 2×2 状态表示的 3 个轮密钥，供批量运算和多重加密复用。

#### `encrypt_with_schedule / decrypt_with_schedule(block, schedule) -> int`

使用预扩展的 `make_schedule` 结果加解密。多重加密和中间相遇攻击使用
这组接口避免重复扩展密钥。

#### `trace_operation_steps(data, key, decrypt=False) -> list[OperationStep]`

返回包含输入在内的 9 个状态步骤。`OperationStep` 的字段：

| 字段 | 说明 |
|---|---|
| `round_index` | 0（输入/AK0/AK2）、1、2 |
| `operation` | `输入`、`AK0`、`NS`、`SR`、`MC`、`AK1`、`AK2`，或 `ISR/INS/IMC` 等 |
| `title` | 中文说明 |
| `state` | 2×2 状态矩阵 |
| `block` | 属性，返回对应的 16 bit 整数 |

GUI 用它同时渲染步骤表和右侧状态矩阵。

#### `trace_encryption / trace_decryption(data, key) -> list[tuple[str, int]]`

兼容旧接口，把 `trace_operation_steps` 压平成
`(步骤说明, 16 bit 中间值)`。

#### `parse_data(text: str, bits: int, name: str) -> int`

解析用户输入。

| 输入 | `bits` | 结果 |
|---|---|---|
| `"1010 0111 0011 1011"` | 16 | `0xA73B` |
| `"0b10100111"` | 8 | `0xA7` |
| `"A73B"` / `"0xA73B"` | 16 | `0xA73B` |
| `"1A2B3C4D"` | 32 | `0x1A2B3C4D` |

规则：忽略空格、下划线、冒号、逗号、连字符；`0x`/`0b` 前缀优先；
无前缀时，恰好 `bits` 位且只含 0/1 按二进制，否则按十六进制。
越界或非法字符抛 `SaesError`。

#### `format_bits(value, bits=16, group=4) -> str`

`0x0738` → `"0000 0111 0011 1000"`。

#### `format_hex(value, bits=16) -> str`

`0x0738` → `"0738"`（固定宽度、大写）。

#### `gf_mul(a: int, b: int) -> int`

GF(2⁴) 乘法，测试中用于验证矩阵性质。

### 4.2 `saes.text`

| 接口 | 说明 |
|---|---|
| `pad(data: bytes) -> bytes` | PKCS#7 填充（总是补满一组） |
| `unpad(data: bytes) -> bytes` | 校验并去除填充 |
| `split_blocks(data) -> list[int]` | 每 2 字节切成 16 bit 分组 |
| `join_blocks(blocks) -> bytes` | 分组拼回字节串 |
| `encrypt_bytes(data, key) -> bytes` | 任意字节串加密 |
| `decrypt_bytes(cipher, key, unpad_data=True) -> bytes` | 字节串解密 |
| `encrypt_text(text, key, encoding="utf-8") -> bytes` | 字符串加密 |
| `decrypt_text(cipher, key, encoding="utf-8") -> str` | 字符串解密 |
| `to_hex(data, group=2) -> str` | 大写十六进制，默认每 2 字节空一格 |
| `to_display(data) -> str` | 可打印字符原样，不可打印显示 `\xNN` |

示例：

```python
from saes.text import encrypt_text, decrypt_text, to_hex

cipher = encrypt_text("ok", 0xA73B)
to_hex(cipher)                 # "0738 5ABE"
decrypt_text(cipher, 0xA73B)   # "ok"
```

`decrypt_bytes(..., unpad_data=False)` 会保留填充，供 CBC 篡改演示使用。

### 4.3 `saes.vectors`

```python
@dataclass(frozen=True)
class TestVector:
    key: int
    plaintext: int
    ciphertext: int

@dataclass(frozen=True)
class VectorResult:
    vector: TestVector
    actual: int
    passed: bool
```

| 接口 | 说明 |
|---|---|
| `generate_vectors(count, seed=None, key=None) -> list[TestVector]` | 随机生成向量；固定 `seed` 可复现 |
| `vectors_to_csv(vectors) -> str` | 序列化为 `key,plaintext,ciphertext` |
| `parse_vectors(text) -> list[TestVector]` | 解析 CSV/制表符/空格分隔文本，支持中英文表头 |
| `check_vectors(vectors) -> list[VectorResult]` | 逐条重算并比对 |

`parse_vectors` 跳过空行与 `#` 注释，每行必须有 3 列。
`FEEC` 这类全字母的十六进制值不会被误判为表头。

### 4.4 `saes.multi`

| 接口 | 公式 / 说明 |
|---|---|
| `split_key32(key) -> (K1, K2)` | 高 16 位、低 16 位 |
| `split_key48(key) -> (K1, K2, K3)` | 三段 16 位 |
| `double_encrypt(P, key32)` | `E_K2(E_K1(P))` |
| `double_decrypt(C, key32)` | `D_K1(D_K2(C))` |
| `triple_encrypt_ede2(P, key32)` | `E_K1(D_K2(E_K1(P)))` |
| `triple_decrypt_ede2(C, key32)` | `D_K1(E_K2(D_K1(C)))` |
| `triple_encrypt_ede3(P, key48)` | `E_K3(D_K2(E_K1(P)))` |
| `triple_decrypt_ede3(C, key48)` | `D_K1(E_K2(D_K3(C)))` |
| `verify_key32(key, pairs) -> bool` | 检查候选密钥是否满足全部明密文对 |
| `meet_in_the_middle(pairs, progress=None, cancel_event=None) -> list[int]` | 恢复 32 bit 密钥 |

`meet_in_the_middle` 参数：

* `pairs`：`[(P, C), ...]`，至少一组；
* `progress(done, total, phase)`：进度回调，`total = 2 * 65536`；
* `cancel_event`：`threading.Event`，置位后抛 `AttackCancelled`。

实现分两阶段：正向枚举 K1 建立 `中间值 → K1 列表` 哈希表；反向枚举 K2
解密 C 并查表；最后用全部 `pairs` 过滤碰撞。时间复杂度 `O(2^16)`，
空间复杂度 `O(2^16)`。

```python
from saes.multi import double_encrypt, meet_in_the_middle

key = 0x1A2B3C4D
pairs = [(p, double_encrypt(p, key)) for p in (0x1234, 0xABCD, 0x5555)]
meet_in_the_middle(pairs)   # [0x1A2B3C4D]
```

### 4.5 `saes.modes`

| 接口 | 说明 |
|---|---|
| `cbc_encrypt(data, key, iv) -> bytes` | CBC 加密，自动填充 |
| `cbc_decrypt(cipher, key, iv, unpad_data=True) -> bytes` | CBC 解密 |
| `cbc_encrypt_details(data, key, iv) -> list[tuple]` | 每行 `(序号, 明文分组, 异或结果, 密文分组)` |
| `flip_bit(cipher, block_index, bit_index=7) -> bytes` | 翻转指定密文分组的一位 |
| `xor_block(left, right) -> int` | 两个 16 bit 分组异或 |

`iv` 必须为 16 bit；`block_index` 从 0 开始，`bit_index` 0 表示最低位。
`cbc_decrypt(..., unpad_data=False)` 用于观察篡改后的原始字节。

## 5. GUI 集成说明

* `gui/app.py::SaesApp` 在构造时创建五个页面，所有回调都是普通方法；
* 加解密是微秒级操作，直接在 Tk 主线程执行；
* 中间相遇攻击约 1 秒，放在 `threading.Thread` 中，通过
  `queue.Queue` 回传进度，主线程用 `root.after(80, ...)` 轮询，
  避免 Tk 卡死；
* 颜色、字体、间距集中在 `gui/theme.py`，`app.py` 不写死颜色值；
* 第 1 关用 `tk.Canvas` 重绘 2×2 状态矩阵（`_draw_state`），
  点击步骤表任意行时通过 `<<TreeviewSelect>>` 更新；
* 主题的 `make_hint_label` 默认 `wraplength=1020`，长说明文字会自动换行。

## 6. 扩展指南

### 6.1 新增一种工作模式（例如 CFB）

1. 在 `saes/modes.py` 中按既有风格实现 `cfb_encrypt/cfb_decrypt`
   （输入输出都是 `bytes`，密钥/IV 用 `int`）；
2. 在 `tests/test_saes.py` 增加往返测试和“已知首分组”测试；
3. 在 `gui/app.py` 的 `_build_cbc` 中复制一个卡片，或新增标签页；
4. 在 `docs/用户指南.md` 和 `README.md` 中补充说明。

### 6.2 新增一种多重加密结构

在 `saes/multi.py` 中组合 `encrypt_block/decrypt_block` 即可，注意解密
顺序必须完全相反。建议同时补一个 `test_*_round_trip`。

### 6.3 批量处理大量分组

单分组函数每次都会扩展密钥，批量场景应使用：

```python
schedule = make_schedule(key)
for block in blocks:
    encrypt_with_schedule(block, schedule)
```

## 7. 代码规范对照

| 作业要求 | 本项目的做法 |
|---|---|
| 4.1 变量命名 | 使用 `plaintext`、`ciphertext`、`round_keys`、`block_index` 等描述性名字；短名仅用于局部循环与数学符号（`a, b`、`n0..n3`） |
| 4.2 代码注释 | 模块/类/公开函数都有中文 docstring，说明参数、返回值和异常；只对不直观的位运算、状态布局、算法步骤写行内注释，不逐行复述代码 |
| 4.3 函数式编程 | 每个函数只负责一件事：S 盒替换、行移位、列混淆、填充、CBC、MITM 分别封装；GUI 回调只做解析和展示 |

## 8. 验证与测试

```bash
python -m unittest discover -s tests -t . -v
```

共 56 项测试。测试覆盖：

* 附录 D 的逐条算例：状态布局、S/逆 S 盒、D.2.1 AK、D.2.2 NS、
  D.2.3 SR、D.2.4 MC 与 IMC、D.3 密钥扩展（`K=2D55`）；
* S 盒是 0~15 的置换，逆 S 盒严格互逆；
* GF(2⁴) 乘法性质及表 D.2 的 `4×C=5`；
* 密钥扩展的两组公开数值；
* 两组公开明密文向量与随机往返；
* 输入解析的二进制/十六进制/前缀/非法输入；
* PKCS#7 填充、字符串往返、错误密钥；
* 双重/三重加密往返、MITM 恢复唯一密钥；
* CBC 首分组公式、IV 影响、篡改传播规律；
* 测试向量的生成、CSV 往返、表头兼容与错误检测。

结果见 [测试结果](测试结果.md)。
